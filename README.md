# SQL Ecommerce Sales Analytics

## Project Overview
This project analyzes ecommerce sales data using SQL.
The goal is to identify customer behavior, revenue trends, payment preferences, and top-performing product categories.

---

## Dataset
Dataset: Olist Ecommerce Dataset

Tables used:
- customers
- orders
- order_items
- products
- order_payments

---

## Tools & Technologies
- MySQL
- SQL
- VS Code
- MySQL Workbench

---

## Key Business Questions
1. How many customers and orders exist?
2. Which states generate the most customers?
3. What is the total revenue?
4. Which payment methods are most used?
5. Which product categories generate the highest revenue?
6. What is the average delivery time?

---

## Key Insights
- São Paulo has the highest customer count.
- Total revenue exceeded 15 million.
- Credit card is the most used payment method.
- Average delivery time is 12.5 days.
- Beauty and furniture categories generated high revenue.
